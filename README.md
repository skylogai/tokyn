# tokyn.dev

Umbrella site for Tokyn apps, served via GitHub Pages at https://tokyn.dev.

- `/` — Tokyn landing
- `/skylog/` — Skylog product page
- `/skylog/privacy/`, `/skylog/terms/`, `/skylog/support/` — legal + support

Static HTML, no build step. `CNAME` sets the custom domain; `.nojekyll` disables Jekyll.
